# Wissen

Fachwissen für das Weingut: Analysen im eigenen Keller, Bodenuntersuchung im Betrieb und Bodenverbesserung auf alkalischen Böden im biologischen Weinbau. Die Texte sind Arbeitsanleitungen mit Quellen.

> **Achtung:** Die Texte ersetzen weder amtliche Analysen noch die Beratung durch die Kontrollstelle. Grenzwerte und Zulassungen ändern sich; vor rechtlich relevanten Entscheidungen den aktuellen Rechtstext prüfen.

## Inhalt

| Bereich | Ordner | Inhalt |
|---|---|---|
| Weinanalytik | [weinanalytik/](weinanalytik/) | Welche Analysen ein kleines Weingut selbst machen kann, Schritt-für-Schritt-Anleitungen, Einkaufslisten |
| Bodenuntersuchung | [boden/](boden/) | Probenahme, Feld- und Hofmethoden (Kalk, pH, Nitrat …), Laborbefunde lesen |
| Alkalische Böden | [alkalische-boeden/](alkalische-boeden/) | Nährstofffreisetzung auf Böden mit pH über 7,5 mit im Bio-Landbau zugelassenen Mitteln |
